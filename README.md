# Gento — Генераторы и запчасти

Лендинг и интернет-магазин по продаже и ремонту запчастей для генераторов.

## Возможности

- Каталог запчастей и моделей генераторов
- Поиск по артикулам и совместимости
- Корзина и оформление запросов на расчёт стоимости
- Админ-панель на Filament для управления каталогом, брендами и заказами
- Импорт каталога из CSV
- Полнотекстовый поиск по запчастям

## Стек

- **Backend:** Laravel 13, PHP 8.4
- **Admin:** Filament 4
- **Frontend:** Vite 8, Tailwind CSS 4, Blade
- **Database:** SQLite
- **Testing:** PHPUnit 12

## Быстрый старт

```bash
composer setup
```

Запуск разработки:

```bash
composer run dev
```

## Тесты

```bash
composer run test
```
